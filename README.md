# 📄 Resume Builder

## 📌 Project Overview
The Resume Builder is a web-based application that helps users create professional resumes easily by filling in simple forms. It automatically generates a structured resume with personal details, education, skills, and experience.

- 🎓 Education Details Section  
- 💼 Work Experience Section
